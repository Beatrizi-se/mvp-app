# 🐤 PATO - Planejador Assistido de Tarefas e Organização

PATO é um aplicativo mobile desenvolvido para auxiliar usuários na organização de tarefas e no aumento da produtividade por meio da decomposição de objetivos em etapas menores e mais gerenciáveis.

O projeto foi concebido com foco em acessibilidade cognitiva, oferecendo uma experiência simples e intuitiva para pessoas que enfrentam dificuldades com planejamento, organização e execução de atividades do dia a dia.

## ✨ Funcionalidades

* Criação e gerenciamento de tarefas
* Divisão automática de tarefas complexas em etapas menores
* Acompanhamento do progresso de cada atividade
* Interface intuitiva e amigável
* Assistente inteligente para auxiliar na organização das tarefas
* Edição e personalização de atividades
* Controle de conclusão de etapas

## 🏗️ Arquitetura

O projeto segue uma arquitetura modular com separação entre interface, lógica de negócio e gerenciamento de dados, buscando facilitar a manutenção e evolução da aplicação.

## 📦 Instalação

Clone o repositório:

```bash
git clone https://github.com/Beatrizi-se/pato
```

Acesse a pasta do projeto:

```bash
cd pato
```

Instale as dependências:

```bash
flutter pub get
```

Execute o aplicativo:

```bash
flutter run
```

## 🎯 Objetivo do Projeto

O PATO foi desenvolvido com o propósito de tornar o planejamento de tarefas mais acessível e menos intimidador, incentivando a produtividade por meio da divisão de atividades em etapas claras e alcançáveis.
